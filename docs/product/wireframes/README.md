# WP00 Representative Wireframes

Status: owner-approved WP00 representative evidence; not final art or implementation

The overview contains six low-cost 1280 × 720 layout studies:

1. Minimal combat HUD
2. Focused District Plan
3. Reward/equipment comparison
4. Shop
5. Lap-end Extract / Push decision
6. Run summary

Each study applies the approved hierarchy:

- one phase or decision owns the screen;
- current phase, next event, and immediate action are explicit;
- icons are paired with labels;
- exact consequences appear before confirmation;
- secondary detail is visually subordinate or marked as inspectable;
- combat is not covered by persistent card, backpack, route-history, or rules prose.

These are structural wireframes only. They do not select final art direction, typography, color, animation, iconography, balance values, or implementation ownership beyond the decisions named in `docs/product/WP00_DECISION_PACKET.md`.
